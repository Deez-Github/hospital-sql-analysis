01 — FINDINGS

Five things the data says

Every figure below is produced by the queries in /sql and reproduced in analysis/results.json.

6.5d

Scheduled admissions stay more than twice as long as emergencies

Scheduled cases average 6.5 days against 3.0 for emergencies. With only four scheduled admissions they still generate 26 of the 44 bed-days — 59% of total occupancy from 40% of the caseload.

Capacity planning
77%

Six long-stay patients consume three quarters of all bed-days

Using the ≤3-day / >3-day rule, 6 patients are long stay and account for 34 of 44 bed-days. Length of stay, not admission volume, is the lever that moves occupancy in this dataset.

Resource use
30%

Lagos is the catchment, but seven cities send one patient each

3 of 10 admissions come from Lagos; the remaining 7 are spread across Abuja, Kano, Accra, Ibadan, Enugu, Kaduna and Port Harcourt. Geographic concentration matters more than city count when planning referral capacity.

Catchment
7.5d

Patients aged 60+ stay twice as long on average

Seniors average 7.5 days versus 3.5 for under-40s and 3.75 for the 40–59 band. Only two patients fall in the senior group, so this is a signal to test on a larger extract rather than a conclusion.

Age banding · small n
4

One physician carries 40% of the panel and the longest average stay

Dr. Ade (General Medicine) treats 4 patients for 20 bed-days and a 5.0-day average; Dr. Musa (Internal Medicine) sees 3 with the shortest average stay at 3.67 days. Panel balance is worth reviewing as volume grows.

Workforce
2

Case mix is perfectly flat — every condition appears twice

Malaria, Typhoid, Hypertension, Diabetes and Asthma each affect exactly two patients, so HAVING COUNT(*) > 1 returns the full list. Condition-level comparison is therefore illustrative, not statistically meaningful.

04 — QUERY CATALOGUE

27 queries, five task sets

Each file in /sql is numbered for run order and carries the expected row count in a comment.

01

Retrieving and filtering

5 queries · WHERE, AND, BETWEEN, IN

SELECT *
FROM Patients
WHERE Gender = 'Female'
  AND City = 'Lagos'
  AND Admission_Type = 'Emergency';   -- 1 row: Aisha Bello

SELECT *
FROM Patients
WHERE Condition IN ('Diabetes', 'Hypertension');   -- 4 rows
02

Sorting and aggregation

5 queries · TOP, DISTINCT, COUNT, AVG, GROUP BY

SELECT TOP (3) *
FROM Patients
ORDER BY Length_of_Stay DESC;      -- 8, 7, 6 days

SELECT CAST(AVG(Age * 1.0) AS DECIMAL(10,2)) AS Avg_Age
FROM Patients;                     -- 44.60 (× 1.0 avoids integer division)
03

Strings and dates

5 queries · UPPER, LOWER, CONCAT, YEAR, MONTH, DATENAME

SELECT Patient_ID,
       Patient_Name,
       YEAR(Admission_Date)            AS Admission_Year,
       DATENAME(MONTH, Admission_Date) AS Admission_Month_Name
FROM Patients;
04

Advanced aggregation

6 queries · HAVING, CASE, CTE, business rules

WITH AgeGroup AS
(
    SELECT CASE WHEN Age < 40 THEN 'Young'
                WHEN Age < 60 THEN 'Middle-aged'
                ELSE 'Senior' END AS Age_Group
    FROM Patients
)
SELECT Age_Group, COUNT(*) AS PatientCount
FROM AgeGroup
GROUP BY Age_Group;                -- Young 4 | Middle-aged 4 | Senior 2
05

Keys and joins

6 queries · PRIMARY KEY, FOREIGN KEY, INNER JOIN, RANK()

SELECT D.Doctor_ID,
       D.Doctor_Name,
       COUNT(*) AS Patient_Count
FROM Patients AS P
INNER JOIN Doctors AS D ON P.Doctor_ID = D.Doctor_ID
GROUP BY D.Doctor_ID, D.Doctor_Name
ORDER BY COUNT(*) DESC;            -- Dr. Ade, 4 patients

Reproduce it locally

Any SQL Server instance from 2016 onwards, or Azure SQL. The script set is idempotent — it drops and rebuilds the objects, so it can be re-run safely.

  1. Open sql/00_create_schema.sql in SSMS and execute it.
  2. Run sql/01_load_data.sql (inline inserts, no file paths needed).
  3. Execute tasks 02 → 06 in order.
  4. Optional: 07_reporting_views.sql and 08_data_quality_checks.sql.
-- verify the load (expect 3 and 10)
SELECT COUNT(*) AS Doctors FROM dbo.Doctors;
SELECT COUNT(*) AS Patients FROM dbo.Patients;

-- the headline query
SELECT Admission_Type,
       CAST(AVG(Length_of_Stay * 1.0) AS DECIMAL(10,2)) AS Avg_LOS
FROM dbo.Patients
GROUP BY Admission_Type
HAVING AVG(Length_of_Stay * 1.0) > 4;

-- Emergency | 3.00
-- Scheduled | 6.50
